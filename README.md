# Сначала человек

Студенческий проект о развитии доступной среды и этичной коммуникации с людьми с ОВЗ. Сайт помогает говорить и писать о людях с инвалидностью корректно и проверять доступность среды.

> Сначала человек, потом диагноз.

## О проекте

Проект опирается на принцип «ничего о нас без нас» и на Конвенцию ООН о правах инвалидов. Сайт рассчитан на студентов, преподавателей и сотрудников университета, волонтёров и всех, кто хочет научиться общаться корректно.

## Разделы сайта

| Раздел | Адрес | Что внутри |
|---|---|---|
| Главная | `#home` | миссия, тезисы, навигация по разделам |
| Этичная коммуникация | `#communication` | правила общения, глоссарий терминов, чего избегать, чек-лист тона голоса |
| Доступная среда | `#environment` | принципы POUR, чек-листы для физической среды и для сайта |
| Ресурсы | `#resources` | документы, организации, инструменты, материалы НИУ ВШЭ |
| О проекте | `#about` | команда, форма обратной связи, заявление о доступности |

Сайт состоит из одного файла `index.html`. Разделы переключаются через адрес со знаком `#`, поэтому на каждый можно дать прямую ссылку, например `https://адрес-сайта/#communication`.

## Запуск локально

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере двойным щелчком.

Установка и сборка не нужны. Для шрифта Manrope требуется интернет, без него подставится Arial.

## Публикация на GitHub Pages

1. Загрузите `index.html` и `README.md` в корень репозитория.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите источник **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через минуту-две сайт появится по адресу `https://ваш-логин.github.io/название-репозитория/`.

Для собственного домена добавьте его в **Settings → Pages → Custom domain** и настройте записи DNS у регистратора.

## Технологии

- HTML, CSS и немного JavaScript, без фреймворков и сборки
- шрифт Manrope (Google Fonts) с запасными шрифтами
- переключение разделов по `location.hash`
- светлая и тёмная темы через `prefers-color-scheme`

## Доступность

Сайт сделан с ориентацией на WCAG 2.2 и ГОСТ Р 52872-2019:

- ссылка «Перейти к содержимому» и семантическая разметка (`header`, `nav`, `main`, `footer`)
- управление с клавиатуры и видимый фокус
- контрастная палитра: тёмно-синий `#0B2545`, белый и бирюзовый акцент
- подписи у всех полей формы, заголовки у столбцов таблицы
- светлая и тёмная темы
- сообщения о состоянии чек-листов читаются скринридерами (`aria-live`)

Если вы нашли проблему с доступностью, откройте Issue в репозитории или напишите нам через форму на странице «О проекте».
